# ISI-4 decision 0002 — native execution blocked pending laboratory infrastructure

Recorded 2026-09-18 by the founding steward.

Native wallet and ToDo execution is blocked until the necessary laboratory infrastructure is planned, provisioned, and documented. Existing personal environments and undesignated virtual machines are outside the execution scope.

The infrastructure plan shall identify the native runner and owner, supported OS and browser versions, isolation and network boundaries, installation and reset procedures, automation capabilities, artifact and evidence storage, service dependencies, resource requirements, and recovery procedures. Provisioning and qualification records shall establish the implemented configuration before native execution begins.

The production-fidelity policy, intake implementation, and static BSV Desktop 2.8.5 findings remain in effect. This decision defers native execution; it records no wallet or application failure. ISI-4-V001 through V004 remain unexecuted and no ToDo demonstration PASS is issued.
